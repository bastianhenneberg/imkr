imkr 🐝

A terminal multiplexer for you and your coding agents. tmux's keys and sessions, tiling and floating panes, and an eye on every agent: working, waiting for you, or done. On this machine and on all your others.

Say it like Imker, German for beekeeper: it tends the hives your agents work in.

What lives where

The names follow tmux: a session holds windows, a window holds panes. Each session is its own server and keeps running when you close the terminal. A hive is imkr's own: a saved map of sessions on all your machines, brought back with one command.

Four states, one glance

Every pane running a coding agent (Claude Code, Codex, opencode, aider, gemini, pi and more) shows what it is doing. Hooks report the exact state; without them imkr reads the screen.

● working

Busy with your prompt. Leave it.

◆ blocked

Asks you something. The tab turns red, the bell rings, a notification goes out.

✦ done

Finished while you looked elsewhere. Clears once you look.

✓ idle

Waiting for the next prompt.

Server and client

The server owns every terminal and draws the screen. Your terminal runs a thin client that sends keys and shows the picture. Detach, and only the client goes; the shells and agents keep working.

    S2[nvim] <--> P2

Scripts, agents and the MCP server use the same socket as the client: one request, one answer.

Every machine, one screen

The machine you sit at is the operator (⌂). Every connection starts there, with your ssh keys, so a server never needs ssh back to your laptop. Switching to a session elsewhere keeps keys, clipboard and links local.

Agents talk to each other

imkr msg server:api/claude "…" types a message into another agent once it is idle, never into a question it asks. When the other machine is out of reach, the message waits in an outbox and is picked up later.

And to colleagues

A colleague with their own imkr becomes a contact. Messages go over a VPN when you share one, otherwise through AI Brain. Either way they wait in the inbox until accepted, and a contact can only send text: no screens, no keys, no shell.

flowchart LR
    A["imkr msg martin:api/claude"] --> Q{contact}
    Q -->|shared VPN| N[HTTP to martin's imkr web]
    Q -->|no shared network| B[AI Brain]

    N --> I[inbox · Ctrl+B i]

CLI mode: an agent per task

ai-brain-cli agent takes an AI Brain task, writes what the agent needs to know and starts Claude Code or Codex on it. With --imkr it opens a window in imkr for it. The CLI owns context, task and sign-in; imkr owns the window, the state and the messages.

Getting started

  1. Install

    Linux, x86_64 or aarch64. The binary lands in ~/.local/bin.

    curl -fsSL https://raw.githubusercontent.com/bastianhenneberg/imkr/main/install.sh | sh

  2. Open a session

    Press Ctrl+B and wait: a menu lists every key. Enter picks with the arrows.

    imkr

  3. Let agents report

    Exact states from Claude Code, and agents that know how to message each other.

    imkr hooks --install imkr skill --install

  4. Add a machine

    ssh without a password, then it stays in the sidebar.

    imkr --host server # offers to install imkr there

  5. Take it along

    In a VPN, every machine's agents on your phone, paired with a QR code.

    imkr web pair
